# تحويل النظام إلى APK من الهاتف فقط

## الطريقة الأسهل: GitHub Actions

### 1) إنشاء حساب GitHub
من الهاتف افتح GitHub وأنشئ حسابًا أو سجّل الدخول.

### 2) إنشاء مستودع جديد
- اضغط + ثم New repository.
- اكتب مثلًا: student-card-system
- اختر Public أو Private.
- أنشئ المستودع.

### 3) رفع ملفات المشروع
بعد فك ضغط ZIP:
- افتح المستودع.
- اختر Add file ثم Upload files.
- ارفع كل ملفات المشروع والمجلدات الموجودة بداخله.
- مهم جدًا: ارفع مجلد `.github/workflows` أيضًا.
- اضغط Commit changes.

### 4) تشغيل بناء APK
- افتح تبويب Actions داخل المستودع.
- اختر Build Android APK.
- اضغط Run workflow.
- انتظر حتى تكتمل العملية.

### 5) تنزيل APK
بعد نجاح العملية:
- افتح عملية البناء الناجحة.
- انزل إلى Artifacts.
- اختر studentcards-apk.
- نزّل الملف إلى الهاتف.
- فك الضغط إذا لزم، ثم ثبّت APK.

## ملاحظات
- أول بناء قد يستغرق وقتًا طويلًا لأن Android SDK/NDK ومكونات Kivy يتم تجهيزها.
- لا تحذف buildozer.spec.
- ملف بطاقة الجامعة موجود داخل assets/card_template.jpg.
- إذا ظهر خطأ في البناء، أرسل لي صورة الخطأ وسأعدّل المشروع لك.

## تحسينات النسخة القادمة
يمكن إضافة التصدير إلى PDF من الهاتف، QR Code، طباعة A4، استيراد Excel، وتحديد عدة طلاب للطباعة دفعة واحدة.
