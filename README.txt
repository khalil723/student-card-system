# نظام بطاقات الطلاب - واجهة Android احترافية

هذه نسخة واجهة هاتف محسنة مبنية بـ Kivy + SQLite، وتستخدم صورة بطاقة الجامعة المرفقة كقالب معاينة.

المزايا:
- لوحة رئيسية بإحصائية عدد الطلاب.
- شاشة إدارة الطلاب.
- بحث بالاسم أو الرقم الجامعي.
- إضافة وتعديل وحذف.
- اختيار صورة الطالب من الهاتف.
- معاينة البطاقة فوق التصميم المرفق.
- قاعدة بيانات SQLite محلية.
- إعداد جاهز للبناء عبر Buildozer.

بناء APK على Linux/WSL:
1. ثبّت Python وBuildozer وAndroid build tools.
2. داخل المجلد:
   pip install buildozer
3. نفّذ:
   buildozer android debug
4. سيظهر APK داخل مجلد bin.

ملاحظة:
النسخة الحالية تضبط واجهة التطبيق والمعاينة. في خطوة الإنتاج التالية يمكن إضافة:
- توليد PDF فعلي من الهاتف.
- 4/8 بطاقات A4.
- QR Code.
- طباعة مباشرة.
- استيراد Excel.
- شاشة إعدادات الشعار واسم الجامعة.
- تسجيل دخول وصلاحيات المستخدمين.
